# ZeroTrace Converter Pro

**ブラウザ完結型・セキュアな多機能ファイル変換ツール**

ZeroTrace Converter Proは、Google Apps Script (GAS) 上で動作するWebアプリケーションです。
最大の特徴は **「サーバーにファイルをアップロードしない」** こと。
画像加工、PDF変換、結合などのすべての処理をブラウザ上のJavaScriptで完結させることで、高度なセキュリティとプライバシー保護を実現しています。

![License](https://img.shields.io/badge/license-MIT-green.svg)

## 🌟 特徴

*   **完全ローカル処理**: ファイルデータが外部サーバーに送信されることはありません。機密情報の取り扱いに最適です。
*   **インストール不要**: ブラウザさえあれば、PC、タブレット、スマートフォンどこからでも利用可能です。
*   **直感的なUI**: Google Material Design 3 を意識したモダンで使いやすいインターフェース。

## 🛠 機能一覧

### 1. 画像加工 (Image Editor)
高度な編集機能を搭載しています。
*   **基本編集**: トリミング、リサイズ、回転。
*   **デコレーション**:
    *   **図形追加**: 四角、円、角丸四角、吹き出し（角・丸）、ブロック矢印。
    *   **文字追加**: フォントサイズ、色の変更に対応。
    *   **手書き**: マーカーによるハイライト（フリーハンド描画）。
    *   **スタイル編集**: 塗りつぶしの有無、枠線の色・太さ、基本色プリセット/カラーピッカー。
*   **最適化保存**: ファイルサイズ（KB）を指定して保存可能。画質と解像度を自動調整して目標サイズに収めます。
*   **ファイル操作**: ドラッグ＆ドロップでの読み込み、編集中画像の差し替え、リセット機能。

### 2. 画像 → PDF変換 (Image to PDF)
*   **一括変換**: 複数の画像（JPG, PNG）をまとめて1つのPDFファイルに変換。
*   **並べ替え**: ドラッグ＆ドロップでページ順序を直感的に変更可能。

### 3. PDF → 画像変換 (PDF to Image)
*   **プレビュー機能**: PDFの内容をブラウザ上で確認しながら操作可能。
*   **個別/一括保存**:
    *   表示中のページのみを画像として保存。
    *   全ページを画像化し、ZIPファイルとして一括ダウンロード。

### 4. PDF編集 (PDF Tools)
*   **ファイル結合**: 複数のPDFファイルを1つに結合。
*   **ページ編集**:
    *   不要なページの削除。
    *   ページの回転（90度ごと）。
    *   ファイルまたぎでのページ並べ替え。

## 💻 技術スタック

*   **Platform**: Google Apps Script (Web App)
*   **Frontend**: HTML5, CSS3, JavaScript (ES6+)
*   **Framework**: Bootstrap 5.3
*   **Libraries (CDN)**:
    *   `Cropper.js`: 画像トリミング
    *   `Fabric.js`: 図形・文字描画
    *   `PDF.js`: PDFレンダリング（画像化）
    *   `pdf-lib`: PDF生成・編集
    *   `JSZip`: ZIP圧縮
    *   `SortableJS`: ドラッグ＆ドロップ並べ替え

## 🚀 セットアップ手順

1.  **Googleドライブでプロジェクト作成**
    *   Googleドライブを開き、「新規」>「その他」>「Google Apps Script」を選択。
2.  **コードの記述**
    *   `コード.gs` (サーバーサイド): 以下の関数のみ記述（または既存のまま）。
        ```javascript
        function doGet() {
          return HtmlService.createTemplateFromFile('index')
            .evaluate()
            .setTitle('ZeroTrace Converter Pro')
            .addMetaTag('viewport', 'width=device-width, initial-scale=1');
        }
        ```
    *   `index.html` (クライアントサイド): 提供された最新のHTMLコードをすべて貼り付けます。
3.  **デプロイ**
    *   エディタ右上の「デプロイ」>「新しいデプロイ」をクリック。
    *   **種類の選択**: 「ウェブアプリ」
    *   **次のユーザーとして実行**: 「自分」
    *   **アクセスできるユーザー**: 利用範囲に合わせて設定（「全員」など）
    *   「デプロイ」をクリックし、発行されたURLを開いて完了です。

## ⚠️ 注意事項・制約

*   **ブラウザメモリ依存**: すべての処理をクライアント（ブラウザ）で行うため、端末のスペックに依存します。数GBを超えるような巨大な処理はクラッシュの原因になります。
*   **編集の不可逆性**: 画像加工において、「トリミングモード」と「デコレーションモード」を行き来すると、描画内容は画像として統合され、再編集（図形の移動など）ができなくなります。
