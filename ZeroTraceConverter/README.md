# LocalDoc Studio

**セキュアで軽量な、ブラウザ完結型ドキュメント編集ツール**

LocalDoc Studioは、Google Apps Script (GAS) 上で動作するWebアプリケーションです。
最大の特徴は、**アップロードされたファイルが外部サーバーに送信されない**ことです。
画像処理、PDF結合、ページ削除、書き込みなどのすべての処理をブラウザ（クライアントサイド）のJavaScriptのみで完結させることで、高いセキュリティとプライバシー保護を実現しています。

## 🌟 主な機能

### 1. 高機能 画像エディタ (Image Editor)
*   **基本編集**: 
    *   トリミング (Cropper.js)
    *   回転（90度単位）、リサイズ
*   **アノテーション (Fabric.js)**: 
    *   図形挿入（四角、角丸、丸、吹き出し、矢印）
    *   テキスト入力（フォントサイズ、色、位置の再編集が可能）
    *   手書き機能（マーカー、蛍光ペン）
    *   オブジェクトの移動、削除、色変更などのプロパティ編集
*   **設定保持**: ペンの太さや色などの設定をブラウザ(LocalStorage)に自動保存。

### 2. PDF マネージャー (PDF Manager)
*   **ページ整理**: ドラッグ＆ドロップによる直感的なページ並べ替え (SortableJS)。
*   **結合・削除**: 複数のPDFファイルを結合したり、不要なページを削除。
*   **書き込み連携**: 
    *   任意のページを選択して「画像エディタ」へ転送。
    *   文字や図形を書き込んだ後、即座にPDFプレビューへ反映。
*   **多彩な保存形式**:
    *   **PDF結合保存**: 編集・並べ替え後の状態を1つのPDFファイルとして保存。
    *   **画像保存**: 全ページを一括ZIP保存、または個別画像として保存。

## 🛠 技術スタック

*   **Platform**: Google Apps Script (Web App)
*   **UI Framework**: Bootstrap 5
*   **Core Libraries (CDN)**:
    *   `Fabric.js`: 高度なキャンバス描画・オブジェクト操作
    *   `PDF.js`: PDFファイルのレンダリング（画像化）
    *   `pdf-lib`: PDFファイルの生成・編集・結合
    *   `Cropper.js`: 画像トリミング
    *   `SortableJS`: ドラッグ＆ドロップUI
    *   `JSZip`: ファイル圧縮処理

## 📥 セットアップ手順

1.  Googleドライブ上で新規の **Google Apps Script** プロジェクトを作成します。
2.  `Code.gs` にサーバーサイドコードをコピーします（ログ機能用）。
3.  `index.html` ファイルを作成し、HTMLコードをすべてコピーします。
4.  「デプロイ」 > 「新しいデプロイ」 > 「ウェブアプリ」を選択します。
    *   **アクセスできるユーザー**: 「全員」（または組織内の設定に合わせてください）
5.  発行されたURLにアクセスして利用開始します。

## ⚠️ 注意事項

*   **ブラウザ互換性**: 最新の Google Chrome, Edge での動作を推奨します。
*   **メモリ制限**: すべての処理をブラウザのメモリ上で行うため、数百ページを超える巨大なPDFや、極端に高解像度な画像を大量に扱うとブラウザが重くなる場合があります。
*   **Googleの仕様**: GASの仕様変更により、ダウンロード時の挙動などが影響を受ける場合があります（v2.1.1にて画面遷移問題を対策済み）。
